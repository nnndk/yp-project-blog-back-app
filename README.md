# yp-project-blog-back-app

**Yandex Practicum Java Middle Project. Blog Backend App**

В данном репозитории лежит учебный проект, разработанный в рамках курса Java Middle на платформе Yandex Practicum.

Проект представляет собой блог, его подробное опсиание можно найти в курсе. Фронтенд часть уже была написана, моя задача в этом проекте - написать бэкенд.


## Структура репозитория

| Объект | Описание |
|--------|----------|
| `my-blog-back-app/` | Бэкенд, написанный мной в рамках прохождения курса |
| `my-blog-front-app/` | Фроненд, подготовленный авторами курса для получения полноценного веб-приложения |


## Запуск приложения

Запуск приложения состоит из двух этапов: запуск бэкенда и запуск фронтенда.

### Запуск фронтенда

Для запуска фронтенда достаточно запустить docker-контейнер командой `docker compose up -d`, после чего приложение будет доступно по адресу `http://localhost:90/`

Проблемы, с которыми я столкнулся:

1. Порт `80` был занят службой IIS, поэтому внешний порт я поменял на `90`

### Запуск бэкенда

Для запуска бэкенда необходимо:

1. В директории `yp-project-blog-back-app/my-blog-back-app/src/main/resources` создать папку `storage` и в ней папку `post-image`. Данные папки используются для хранения изображений (картинок постов) (Намеренно не создаю их автоматически, чтобы было полное понимание, где находится хранилище)

2. Находясь в директории `my-blog-back-app/`, выполнить команду **gradlew bootrun**


### Тесты

В проекте соедржатся тесты двух типов: **unit** и **интеграционные**. Все тесты запускаются командой `gradle test`.

Unit-тесты перенес из прошлой итерации "как есть", они не зависят от Spring Boot.

Интеграционные тесты при переносе доработал следующим образом:

1. Пакет **repository**:

    - тесты больше не нуждаются в кастомных конфигурациях (RepositoryTestConfig)

    - заменил `@SpringJUnitConfig(RepositoryTestConfig.class)` на `@JdbcTest` (не @DataJdbcTest, поскольку репозитории без наследования CrudRepository все-равно не находятся автоматически)

    - добавил импорты нужных бинов (`@Import({...})`)

2. Пакет **Service**:
    
    - заменил `@SpringJUnitConfig(ServiceRepositoryTestConfig.class)` на `@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.MOCK)` (без запуска сервера, поскольку тестируем только сервисы)


## Итерации

Данный проект будет модифицироваться по мере прохождения курса, поскольку предполагается работа с ним в несколько итераций, поэтому описание будет дополняться и изменяться. Ниже представлены описания итераций.

### Итерация 01: module01-sprint03

Первая итерация посвящена фреймворку Spring в чистом виде. Фронтенд уже подгтовлен, его необходимо лишь запустить. Бэкенд необходимо написать самостоятельно, после чего его нужно развернуть в контейнере сервлетов (Apache Tomcat) и объединить с фронтендом.

### Итерация 02: module01-sprint04

Во второй итерации необходимо переписать бэкенд (как саму лоигку, так и тесты) с чистого Spring на Spring Boot. Также необходимо заменить систему сборки: в моем случае с **Maven** на **Gradle**.
