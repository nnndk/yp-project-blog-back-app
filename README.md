# yp-project-blog-back-app

**Yandex Practicum Java Middle Project. Blog Backend App**

В данном репозитории лежит учебный проект, разработанный в рамках курса Java Middle на платформе Yandex Practicum.

Проект представляет собой блог, его подробное опсиание можно найти в курсе. Фронтенд часть уже была написана, моя задача в этом проекте - написать бэкенд.


## Структура репозитория

| Объект | Описание |
|--------|----------|
| `my-blog-back-app/` | Бэкенд, написанный мной в рамках прохождения курса |
| `my-blog-front-app/` | Фроненд, подготовленный авторами курса для получения полноценного веб-приложения |


## Запуск приложения

В данный момент запуск приложения состоит из двух этапов: запуск бэкенда и запуск фронтенда.

### Запуск фронтенда

Для запуска фронтенда достаточно запустить docker-контейнер командой `docker compose up -d`, после чего приложение будет доступно по адресу `http://localhost:90/`

Проблемы, с которыми я столкнулся:

1. Порт `80` был занят службой IIS, поэтому внешний порт я поменял на `90`

### Запуск бэкенда

Для запуска бэкенда необходимо:

1. Установить **Apache Tomcat** версии не ниже <i>10.1</i> и настриоть (раскомментировать пользователя и задать пароль)

2. Запустить Tomcat: перейти в `{Apache Tomcat директория}/bin` и запустить файл <i>startup.bat</i> (windows) / <i>startup.sh</i> (linux)

3. Выполнить, находясь в директории `my-blog-back-app/`, последовательно 3 команды:

    - mvnw install

    - mvnw clean

    - mvnw package

4. После этого скопировать файл `my-blog-back-app/target/api.war` в `{Apache Tomcat директория}/webapps` и подождать несколько секунд, пока Tomcat добавит/обновит приложение

### Итерация 01: module01-sprint03

Первая итерация посвящена фреймворку Spring в чистом виде. Фронтенд уже подгтовлен, его необходимо лишь запустить. Бэкенд необходимо написать самостоятельно, после чего его нужно развернуть в контейнере сервлетов (Apache Tomcat) и объединить с фронтендом.
