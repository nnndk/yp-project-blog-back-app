# yp-project-blog-back-app

**Yandex Practicum Java Middle Project. Blog Backend App**

В данном репозитории лежит учебный проект, разработанный в рамках курса Java Middle на платформе Yandex Practicum.

Полный проект представляет собой блог, но в данном репозитории лежит тоько его бэкенд часть. Архив с фронтендом, а также полное описание проекта можно найти на платформе.

## Итерации

Данный проект будет модифицироваться по мере прохождения курса, поскольук предполагается работа с ним в несколько итераций, поэтому описание будет дополняться. Ниже представлены описания итераций.

### Итерация 01: module01-sprint03

Первая итерация посвящена фреймворку Spring в чистом виде. Подробное ТЗ лежит в соответствующем уроке на платформе.
